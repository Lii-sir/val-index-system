# 目标检测指标代码编写规范

## 1. 文件结构

```text
valindex/
+-- metrics/
    +-- det/
        +-- __init__.py
        +-- adapters/
        |   +-- __init__.py
        |   +-- common.py
        |   +-- dataset.py
        |   +-- yolo.py
        |   +-- coco.py
        +-- iou.py
        +-- matching/
        +-- confusion/
        +-- scores/
        +-- ap/
```

约定：

- `adapters` 只负责把外部数据格式转成内部统一格式；
- `dataset.py` 是工程使用的主要入口，按图片文件夹、GT 标签文件夹、推理结果文件夹加载数据；
- `yolo.py`、`coco.py` 是底层格式适配能力，可以被 `dataset.py` 复用；
- 指标函数只接收内部统一格式，不直接解析 YOLO、COCO 或其他外部格式。

## 2. 统一入参格式

### 2.1 数据集级入口

面向工程落地时，推荐统一使用同一个目录级接口：

```python
predictions, targets = metrics.det.load_detection_dataset(
    image_dir="images",
    gt_label_dir="labels_gt",
    pred_label_dir="labels_pred",
)
```

三个文件夹按相同的相对路径匹配：

```text
images/scene/img_001.jpg
labels_gt/scene/img_001.txt
labels_pred/scene/img_001.txt
```

返回值：

```python
predictions = [
    {
        "image_id": "scene/img_001",
        "boxes": [[x1, y1, x2, y2]],
        "labels": [class_id],
        "scores": [score],
    },
]

targets = [
    {
        "image_id": "scene/img_001",
        "boxes": [[x1, y1, x2, y2]],
        "labels": [class_id],
        "scores": [1.0],
    },
]
```

说明：

- `predictions` 和 `targets` 都按图片组织，一张图片对应一个字典；
- `image_id` 使用图片相对路径去掉后缀后的字符串；
- 没有目标时，`boxes`、`labels`、`scores` 都使用空列表；
- GT 的 `scores` 固定填充为 `1.0`，只是为了保持结构统一，指标计算时不作为置信度使用。

### 2.2 单张图片的数据格式

每张图片内部统一使用：

```python
{
    "image_id": "scene/img_001",
    "boxes": [[x1, y1, x2, y2]],
    "labels": [class_id],
    "scores": [score],
}
```

字段要求：

- `boxes`、`labels`、`scores` 长度必须一致；
- `boxes` 使用像素坐标的 `xyxy` 格式：`[x1, y1, x2, y2]`；
- `x1, y1` 表示左上角坐标，`x2, y2` 表示右下角坐标；
- 必须满足 `x2 >= x1`、`y2 >= y1`；
- `labels` 使用非负整数类别编号；
- `scores` 取值范围为 `[0, 1]`。

### 2.3 外部格式适配

外部格式先经过适配器转换，再进入指标函数：

```python
predictions, targets = metrics.det.load_detection_dataset(...)
```

当前目录级入口默认读取 YOLO 标签：、

```text
class_id x_center y_center width height
class_id x_center y_center width height score
```

约定：

- YOLO 坐标是相对图片宽高归一化后的 `xywh`；
- 真实标签一般是 5 列，没有置信度；
- 推理结果一般是 6 列，最后一列是 `score`；
- 适配后统一转成像素坐标 `xyxy`。

## 3. 统一出参格式

标量指标直接返回 `float`：

```python
value = metrics.det.iou(pred_box, target_box)
```

需要返回多项结果时，统一使用字典：

```python
{
    "value": 0.85,
    "details": {
        "per_class": {},
    },
}
```

混淆矩阵、TP/FP/FN 等详细统计至少包含：

```python
{
    "matrix": ...,
    "labels": ...,
    "tp": ...,
    "fp": ...,
    "fn": ...,
}
```

## 4. 错误处理

以下情况必须直接报错：

- 输入路径不存在；
- 图片文件无法读取尺寸；
- 标签文件不存在，且 `missing_ok=False`；
- 外部标签格式不符合约定；
- `boxes`、`labels`、`scores` 数量不一致；
- 框坐标不是 4 个数；
- 框坐标包含 `NaN` 或 `Inf`；
- `x2 < x1` 或 `y2 < y1`；
- 类别编号不是非负整数；
- 置信度不在 `[0, 1]`。

异常类型约定：

- `FileNotFoundError`：文件或文件夹不存在；
- `TypeError`：输入对象类型不正确；
- `ValueError`：输入结构或数值不符合要求。

空数据约定：

- 空预测、空 GT 都是合法输入；
- 没有目标的图片使用空列表表示；
- 分母为 0 或指标无定义时，指标函数返回 `NaN`，不要静默改成 0。
